# 🏥 Three Machine Learning Medical Diagnostic Apps

This repository contains **three separate Streamlit web applications** for medical diagnosis. Each app uses a different machine learning algorithm and dataset.

## 📊 Apps Overview

| Algorithm | Dataset | Features | Task | App Folder |
|-----------|---------|----------|------|------------|
| **Random Forest** | Cleveland Heart Disease (TensorFlow) | 13 | Binary Classification | `Random Forest/` |
| **K-Nearest Neighbors (KNN)** | Wisconsin Breast Cancer (sklearn) | 30 | Binary Classification | `K.N.N/` |
| **Decision Tree** | Pima Indians Diabetes (UCI) | 8 | Binary Classification | `Decision Tree/` |

## 🚀 Live Demos

- **Random Forest (Heart Disease):** [https://rft-heart-risk-check.streamlit.app/](https://rft-heart-risk-check.streamlit.app/)
- **KNN (Breast Cancer):** [https://knn-cancer-check.streamlit.app/](https://knn-cancer-check.streamlit.app/)
- **Decision Tree (Diabetes):** [https://dt-diabetes-risk-analyzer.streamlit.app/](https://dt-diabetes-risk-analyzer.streamlit.app/)



## 🛠️ Local Setup

1. Clone the repository and enter the folder:
   ```bash
   git clone https://github.com/sm2hashmi/Machine_Learning_Projects.git
   cd Machine_Learning_Projects
Ensure that all dependencies are fulfilled by running:
```bash
pip install -r requirements.txt
```

2. Within are three sub-folders; Random Forest Tree, Decision Tree and KNN. Enter into any one of those folders like this:
   ```bash
   cd "Decision Tree"
   cd "KNN"
   cd "Random Forest Tree"
How to run the app is available in each of sub-folder's README.md.
